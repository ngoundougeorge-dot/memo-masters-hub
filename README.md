# Mon Mémoire Facile

Je veux développer une application pour que des clients en quête de rédacteur de mémoire ou rapport de stage passent leur commande. A l’accueil on trouve des tarifs en Franc CFA, des avis étudiants satisfaits de leur notre au rapport écrit, l’assurance d’une rédaction personnalisée avec des sources proprement renseignées pour éviter le plagiat. Une interface client où on peut écrire le sujet de rédaction, insérer des documents permettant au rédacteur de respecter les instructions de l’établissement. Une interface administration ou rédaction pour récupérer les documents et une autre interface cette fois plus Dashboard. Lorsque le client a payé, il recroît une notification avec un statut en cours des le paiement, lorsque tous les documents sont envoyés, le rédacteur doit saisir j’ai tout ce qu’il me faut pour basculer en statut rédactionnel. Une messagerie interne permet d’échanger entre client et rédacteur pour être informé de t’état d’avancement.
